# Bundled label fonts

All four fonts support Polish accents and are bundled for local, offline rendering.

| Engine ID | Family / file | Use |
| --- | --- | --- |
| `sans` | Noto Sans Regular, `NotoSans-Regular.ttf` | Original default |
| `sans-bold` | Noto Sans Bold, `NotoSans-Bold.ttf` | Heavier letter shapes |
| `mono` | Noto Sans Mono Regular, `NotoSansMono-Regular.ttf` | Cable and equipment IDs |
| `serif` | Noto Serif Regular, `NotoSerif-Regular.ttf` | Classic serif labels |

Noto Sans Regular is retained from the original application and is covered by [OFL.txt](OFL.txt).

The three added files come from the official [Noto fonts repository](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf), revision `ffebf8c1ee449e544955a7e813c54f9b73848eac`. Their unmodified license is [Noto-fonts-LICENSE.txt](Noto-fonts-LICENSE.txt), the SIL Open Font License 1.1.
